## 📥 Installation (Termux / Linux)

আপনার Termux বা টার্মিনালে নিচের কমান্ডটি **একবারে কপি করে রান করুন**:

```bash
pkg update && pkg upgrade -y && pkg install python git -y && git clone [https://github.com/THEDARKMAMUN/GXBOMBER](https://github.com/THEDARKMAMUN/GXBOMBER) && cd GXBOMBER && python gxbomber.py
<details>
<summary><b>🔍 Step-by-Step Commands (ধাপে ধাপে চালাতে চাইলে ক্লিক করুন)</b></summary>

# 1. সিস্টেম আপডেট করুন
pkg update && pkg upgrade -y

# 2. প্রয়োজনীয় টুল ইনস্টল করুন
pkg install python git -y

# 3. রিপোজিটরি ক্লোন করুন
git clone [https://github.com/THEDARKMAMUN/GXBOMBER](https://github.com/THEDARKMAMUN/GXBOMBER)

# 4. ডিরেক্টরিতে প্রবেশ করুন
cd GXBOMBER

# 5. টুলটি রান করুন
python gxbomber.py
